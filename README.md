# Block Animations — Forge 1.8.9

Настройка анимации блокхита мечом, как во вкладке Animations у клиентов.
Только визуал: на сервер ничего не отправляется.

## Управление

- **J** или `/anim` — открыть меню
- `/anim exhibition` — сразу выбрать режим

## Режимы

1.8, 1.7, Exhibition, Swank, Swing, Sigma, Push, Slide, Tap, Avatar, Spin

## Настройки в меню

- X / Y / Z — смещение меча
- Scale — размер
- Swing speed — скорость взмаха (1 = ваниль)
- Offset always — применять смещение и размер и без блока
- Visual blockhit — рука машет, если кликаешь во время блока (как в 1.7)
- Preview — меч анимируется, пока открыто меню

Если стоит LabyMod, выключи в его настройках «1.7 animations» для меча,
чтобы анимации не конфликтовали.
