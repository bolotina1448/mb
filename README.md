# Black Nametags — Forge 1.8.9

Ники с чёрным фоном, полностью видны через блоки (в ванилле — бледные).
Ники крадущихся игроков и скрытые сервером ники не показываются.

Команды (`/nametags` или `/nt`):

- `/nt` — статус
- `/nt on` / `/nt off`
- `/nt opacity 80` — насколько чёрный фон (0–100)
- `/nt walls` — вкл/выкл яркость через стены
- `/nt shadow` — тень текста
