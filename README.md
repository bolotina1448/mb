# Motion Blur — Forge 1.8.9 (работает с LabyMod)

Плавный «шлейф» как в эдитах: каждый кадр смешивается с предыдущими,
поэтому при поворотах камеры, беге и PvP за всем тянется затухающий след.
Длина шлейфа не зависит от FPS.

## Как собрать .jar

1. Установи **JDK 17** (например, Adoptium Temurin 17: https://adoptium.net).
   Java 8 для самого Майнкрафта Gradle скачает сам.
2. Распакуй папку `MotionBlur`, открой в ней терминал (на Windows:
   в адресной строке проводника напиши `cmd` и нажми Enter).
3. Выполни:
   - Windows: `gradlew.bat build`
   - Linux/macOS: `./gradlew build`
4. Первая сборка идёт 5–10 минут (качает Minecraft и Forge).
   Готовый мод: `build/libs/MotionBlur-1.1.0.jar`.

## Установка

Скопируй `MotionBlur-1.1.0.jar` в папку `mods`:
- обычный Forge: `%appdata%\.minecraft\mods`
- LabyMod 3 + Forge: тоже `%appdata%\.minecraft\mods`, запуск через
  профиль LabyMod с Forge 1.8.9

## Управление

| Что | Как |
|---|---|
| Вкл/выкл | клавиша **M** (меняется в Настройки → Управление → Motion Blur) |
| Сила 1–10 | `/mb 7` |
| Вкл / выкл командой | `/mb on`, `/mb off` |
| Размытие поворота камеры 0–10 | `/mb camera 6` |
| Статус | `/mb` |
| Через меню | Mods → Motion Blur → Config |

Сила 5–7 — аккуратный блюр, 9–10 — очень сильный шлейф, как в эдитах.

## Если не работает

- В OptiFine выключи **Fast Render** (Настройки графики → Performance).
- Шейдерпаки OptiFine могут конфликтовать — проверь без шейдеров.
- Встроенный motion blur LabyMod (если включён) лучше выключить,
  чтобы эффекты не складывались.
